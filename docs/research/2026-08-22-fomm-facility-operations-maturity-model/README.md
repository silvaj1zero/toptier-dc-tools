# FOMM — Facility Operations Maturity Model para data centers

**Data:** 2026-08-22  
**Tipo:** pesquisa técnica (fontes primárias)  
**Idioma:** pt-BR

## TL;DR

A fonte primária **é** o Schneider Electric **White Paper 197**, *Facility Operations Maturity Model for Data Centers*, **Revision 1**, autores **Jennifer Schafer** e **Patrick Donovan**, copyright **2014**. Cinco níveis (1 Initial/ad hoc → 5 Optimized), **7 disciplinas / 26 elementos**. A lista **completa de sub-elementos (~80)** está no modelo embutido (~80 páginas), **não** no WP de 9 páginas. O paper **não** define fórmula oficial de nível final nem pesos.

Melhor base para um *quick assessment* online de 15–20 perguntas: **FOMM (7 disciplinas)**, com linguagem CMMI-like. EPI DCOS é o padrão de maturidade operacional mais completo (11 disciplinas), mas é pesado demais para 15–20 Q. Green Grid DCMM é o modelo errado (eficiência energética, não O&M).
